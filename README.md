# StudyFlow – build the Android app (free)

1. Create a free account at https://github.com and make a **new repository** (any name, Public or Private).
2. Upload everything in this folder to it (on the repo page: **Add file → Upload files**, drag all files AND the hidden `.github` folder; or use git).
   Make sure `.github/workflows/build-apk.yml` ends up in the repo.
3. Open the **Actions** tab → **Build Android APK** → **Run workflow**. Wait about 5–8 minutes.
4. Open the finished run → **Artifacts** → download **StudyFlow-apk** (a zip containing `app-debug.apk`).
5. Send the APK to your phone (WhatsApp / Telegram / Drive), open it from Files, and allow "Install unknown apps" when asked.

Your data stays on the phone. Use Settings → Data → Export to back up.
